クライアント証明書のインストール

Open Caravan は、許可された端末からだけ開けるようになっています。お使いの端末に、管理者から受け取った証明書を一度だけインストールしてください。

はじめに

管理者から次の2つを受け取ります。

.p12
証明書ファイル例: open-caravan-tanaka-iphone.p12
🔑
パスワード口頭・チャットなど、証明書ファイルとは別の方法で（password.txt の場合もあります）
必ず「証明書のインストール → Open Caravan を開く」の順番で。インストール前に Open Caravan のURLを開くと、ブラウザが「証明書なし」を覚えてしまい、ブロック画面が出続けることがあります。

証明書は端末ごとに1つです。他の人や別の端末に渡さないでください。

端末ごとの手順

iPad は「iPhone」と同じ手順です。

  1. 受け取った .p12 ファイルをダブルクリックします。「キーチェーンアクセス」が開きます。
  2. 追加先のキーチェーンで ログイン を選び、追加 を押します。
  3. 証明書のパスワードを入力して OK を押します。Macのログインパスワードを求められた場合はそれも入力します。
  4. Chrome または Safari で、管理者から案内された Open Caravan のURLを開きます。
  5. 「証明書を選択」と表示されたら、Open Caravan で始まる証明書を選んで OK。
  6. 「キーチェーンに保存されたキーを使用しようとしています」と出たら、Macのログインパスワードを入力して 常に許可 を押します。

ブロック画面が出る場合は、ブラウザを ⌘Q で完全に終了してから開き直してください（ウインドウを閉じるだけでは不十分です）。

  1. 受け取った .p12 ファイルをダブルクリックします。「証明書のインポート ウィザード」が開きます。
  2. 保存場所は 現在のユーザー のまま 次へ → ファイル名もそのまま 次へ。
  3. 証明書のパスワードを入力し、次へ。（他のチェック項目はそのままで構いません）
  4. 証明書の種類に基づいて、自動的に証明書ストアを選択する のまま 次へ → 完了。「正しくインポートされました」と出れば完了です。
  5. Chrome または Edge を完全に終了します（タスクバー右下に残っている場合はそれも終了）。
  6. ブラウザを開き、管理者から案内された Open Caravan のURLを開きます。「証明書の選択」で Open Caravan で始まる証明書を選んで OK。

  1. 受け取った .p12 ファイルを端末に保存します（メールの添付やファイル共有から ダウンロード フォルダへ）。
  2. 設定 を開き、上の検索欄で「証明書」と検索して 証明書のインストール を開きます。
    見つからない場合: 設定 → セキュリティとプライバシー → その他のセキュリティ設定 → 暗号化と認証情報 → 証明書のインストール
  3. VPN とアプリユーザー証明書 を選びます。
    「CA 証明書」「Wi-Fi 証明書」ではありません。違う種類で入れると使えません。
  4. 保存した .p12 ファイルを選び、証明書のパスワードを入力します。名前はそのままで OK。
  5. Chrome で、管理者から案内された Open Caravan のURLを開きます。
  6. 「証明書の選択」で Open Caravan で始まる証明書を選んで 選択。
    Chromeを再起動するたびに、この選択画面が1回表示されます。毎回同じ証明書を選んでください。拒否 は押さないでください。

ブロック画面が出る場合は、設定 → アプリ → Chrome → 強制停止 を押してから Chrome を開き直してください（最近使ったアプリから消すだけでは不十分です）。

  1. 受け取った .p12 ファイルを開きます（メールの添付をタップ、AirDrop で受け取る、または「ファイル」アプリでタップ）。
    「プロファイルがダウンロードされました」と表示されたら 閉じる。
  2. 設定 を開き、上部の ダウンロード済みのプロファイル をタップします。
    表示されない場合: 設定 → 一般 → VPN とデバイス管理
  3. インストール をタップし、iPhoneのパスコードを入力します。「署名されていません」等の表示が出ても、管理者から受け取ったものであれば インストール を続けます。
  4. 証明書のパスワードを入力して 次へ → 完了。
  5. Safari で、管理者から案内された Open Caravan のURLを開きます。証明書の選択が出たら Open Caravan で始まる証明書を選びます。
    iPhone・iPad では Safari を使ってください。Chrome などほかのブラウザでは証明書を使えない場合があります。

インストールが終わったら

  1. Open Caravan のログイン画面が表示されたら、自分のログインIDとパスワードでログインします。
  2. 端末に残っている .p12 ファイル（と password.txt）を削除します（メールの添付、ダウンロードフォルダ、「ファイル」アプリなど）。証明書は端末に登録済みなので、ファイルは不要です。
  3. ホーム画面やブックマークに Open Caravan を追加しておくと便利です。

困ったとき

「Sorry, you have been blocked」と表示される
証明書が送られていません。ブラウザを完全に終了して開き直し、証明書の選択で Open Caravan の証明書を選んでください（Android は Chrome の強制停止、Mac は ⌘Q）。それでも表示される場合は、手順のとおりの種類でインストールされているか確認し、管理者に連絡してください。
証明書の選択で「拒否」「キャンセル」を押してしまった
上と同じく、ブラウザを完全に終了してから開き直すと、もう一度選択画面が出ます。
パスワードが違うと言われる
大文字・小文字、数字の 0 と英字の O などを確認してください。分からない場合は管理者に再送を依頼してください。
ログイン画面は出るが、ログインできない
ログインIDとパスワード（証明書のパスワードとは別のもの）を確認してください。分からない場合は管理者にお問い合わせください。
端末をなくした・機種変更した
すぐに管理者へ連絡してください。古い端末の証明書を無効にし、新しい端末用の証明書を発行します。証明書を新しい端末へ移すことはできません。
Open Caravan · 証明書や URL は、院内の管理者からのみ受け取ってください。このページは手順の案内であり、証明書やパスワードを入力・送信する場所はありません。
