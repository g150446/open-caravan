訪問ルートの使い方

1日の訪問の順番・移動時間・距離をまとめて確認し、訪問順と時刻をまとめて組み直す機能です。スタッフの列（担当と同行の組み合わせ）ごとに、その日の訪問を扱います。

  • はじめに
  • ルートを見る
  • ルートを一括変更する
  • ルートに入らないとき
  • 見積もりのしくみ

はじめに（管理者・最初の1回だけ）

ルートは事業所から出て、事業所に戻る形で計算します。管理者が出発地を登録してください。

  1. 画面上の ⚙ 基本設定 を開きます（管理者にだけ表示されます）。
  2. 事業所の欄に入力して 保存する を押します。
    • 住所: 出発・到着地。必須です。
    • 予定間の余白（分）: 「時間を自動調整する」で、訪問と訪問のあいだに足す時間です（準備や記録の時間）。
    • 地図の位置（任意）: 住所から求めた位置がずれるときに使います（やり方）。
    • 回り道の係数・平均時速（km）: 移動時間の見積もりに使います（見積もりのしくみ）。最初は 1.4 と 30 のままで構いません。

ルートを見る

  1. 予定 の画面で、その日のスタッフの列の見出しにある ⋮ を押し、ルートを見る を選びます。
  2. 事業所を出発してから戻るまでの順に、訪問先・移動時間・到着時刻が並びます。上に合計時間と合計距離が出ます。
  3. ルート表示で区切り方を選べます。
    • 午前 / 午後（最初の表示）: 昼にいったん事業所へ戻る2本のルートで計算します。
    • 1日: 戻らずに1本で回ります。
    • 午前・午後: 片方だけを表示します。正午より前に始まる予定が午前です。
  4. 終わったら ‹ カレンダーに戻る を押します。

画面の見方

  • 移動時間: 区間ごとに「12分」のように出ます。「約12分」のように約が付くときは見積もりです。
  • 移動時間が不足しています: 前の訪問の終わりから移動すると、次の訪問の開始に間に合わない区間です。時刻か順番を見直してください。
  • 町名のバッジ 5条西: 訪問先の地域です。同じ地域が続く訪問先は同じ色になり、地域のまとまりが分かります。
  • 施設: 同じ住所（同じ施設など）を続けて訪ねる予定は、1か所の訪問先にまとめて表示します。
  • ナビ: その区間の道順を Google マップで開きます。
  • ↗ このルートを Google マップで開く: ルート全体を Google マップで開きます（訪問先が9か所までのとき）。
  • 印刷する: 紙で持ち出すときに使います。

ルートを一括変更する

訪問の順番と時刻を、その日の分だけまとめて組み直します。変更を保存する を押すまでは保存されません。

  1. 列の見出しの ⋮ → ルートを一括変更する を選びます（ルートを見る画面の右上からも開けます）。
  2. 訪問順を決めます。
    • 手で並べる: 各行の ≡ をドラッグするか、↑ ↓ を押します。
    • 自動で並べる: 近い順に並べる を押すと、事業所から出て戻るまでが短くなる順に並べ替えます。ルートの計算が終わるまでは押せません。
  3. 出発時刻を確かめます。最初は今の予定から逆算した時刻が入っています。必要なら変えてください。
  4. 時間を自動調整する を押します。出発時刻から順に、移動時間と余白を足して、各予定の時刻を5分単位で詰め直します。予定の長さは変わりません。
    • 時刻を動かしたくない予定（約束の時間が決まっている訪問など）は、時間の自動調整の対象外にチェックを入れてから押します。
    • 時刻は各行の入力欄で直接直すこともできます。
  5. やめる予定があれば 🗑 を押します。下の「削除する予定（保存時に削除）」に移り、元に戻す で戻せます。
  6. 変更を保存する を押します。保存しないでやめるときは ‹ 保存せずに戻る を押します。

保存のきまり

  • 変えられるのは、その日の中の時刻だけです。別の日へは移せません。
  • 繰り返し予定は、その日の回だけが変わります（削除も、その回だけ）。
  • 並び順と時刻が合っていないと保存できません。時間を自動調整する を押すか、時刻を直してください。
  • 開いているあいだに誰かが同じ予定を変えていたら、何も保存されません。画面を開き直してやり直してください。

ルートに入らない・位置がずれるとき

次の予定は、画面の下の「ルートに含まれない予定」（一括変更では「ここでは変更しない予定」）に理由と一緒に表示されます。時刻はそのまま残ります。

  • 一般予定: 患者のいない予定（会議など）。
  • 住所が未登録: 患者にも、患者の施設にも住所がありません。患者情報か施設情報に住所を入れてください。
  • 位置が分からない: 住所から地図の位置を求められませんでした。下の手順で位置を入れてください。

地図の位置を入れる

位置が分からないときのほか、郡部の広い「字」などで位置が実際とずれるときにも使います。入れた位置は、住所から求めた位置より優先されます。

  1. パソコンで Google マップを開き、その家（または施設）の場所を右クリックします（スマホは長押し）。
  2. いちばん上に出る「43.0597, 141.7790」のような数字を押すと、コピーされます。
  3. Open Caravan の患者（施設に入居している場合は施設）の 編集 を開き、地図の位置（任意）に貼り付けて保存します。

事業所の位置がずれるときは、基本設定の「事業所」の地図の位置（任意）に同じように入れます。

見積もりのしくみと注意

  • 住所から町丁目・字ごとの代表点の位置を求め、直線距離 × 回り道の係数 ÷ 平均時速で移動時間を見積もります。道路に沿った距離ではないため、実際とは違います。
  • 山や川を回り込む地域で短めに出るときは回り道の係数を、移動が遅めに出るときは平均時速を、基本設定で調整してください。
  • 簡易図は訪問先を直線で結んだもので、道路ではありません。実際の道順は ナビ で確かめてください。
  • 位置を求めるために外部へ送るのは、都道府県と市区町村の名前だけです。番地や患者の氏名は送りません。一度求めた位置は保存され、次からはすぐに表示されます。
  • 住所の位置データ: アドレス・ベース・レジストリ（デジタル庁）を加工した Geolonia 住所データ（CC BY 4.0）。

管理者が Google マップの API キーを設定した場合は、道路に沿った移動時間・距離と地図の画像で表示されます（「約」は付きません）。そのときは、ルートの計算のために住所（氏名は送りません）を Google に送ります。高速道路を使うかどうかも選べます。
